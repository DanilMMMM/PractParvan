## 📌 Стек технологий
- **Платформа:** .NET 9 (C#)
- **Архитектура:** ASP.NET Core MVC
- **База данных:** SQLite + Entity Framework Core 9
- **Аутентификация:** Cookie-based Authentication с разделением прав доступа на основе ролей (`[Authorize(Roles = "...")]`)
- **Безопасность:** Хеширование паролей PBKDF2 (SHA-256 с солью), защита от CSRF (`[ValidateAntiForgeryToken]`), валидация входных данных (`DataAnnotations` + jQuery Validation)
- **Пользовательский интерфейс:** HTML5, CSS3, Bootstrap 5, Bootstrap Icons

## 🚀 Как запустить проект

### Вариант 1: Через Visual Studio
1. Откройте файл решения `VetClinic.sln` в **Visual Studio 2022 / 2025**.
2. Убедитесь, что выбран проект `VetClinic` в качестве запускаемого.
3. Нажмите клавишу **F5** (или зелёную кнопку «Запуск»).
4. База данных SQLite (`vetclinic.db`) создастся и наполнится тестовыми данными **автоматически** при первом запуске!
5. Приложение откроется в браузере.

### Вариант 2: Через командную строку (CLI)
```bash
cd VetClinic
dotnet run
```
После запуска откройте в браузере адрес: `http://localhost:5000` (или порт, указанный в консоли).

## 📋 Основной функционал системы

### 1. Главная страница (Гость / Неавторизованный пользователь)
- Описание ветеринарной клиники «ВетЗабота» и её преимуществ.
- Каталог популярных услуг с ценами и длительностью приёма.
- Список врачей клиники с указанием специализации.
- Счётчики показателей (количество пациентов, проведённых приёмов, довольных клиентов).
- Кнопки быстрой записи на приём и входа/регистрации.

### 2. Регистрация и Авторизация
- Регистрация с заполнением ФИО, логина, email, телефона, пароля и **выбором роли** (Клиент / Ветеринар).
- При выборе роли «Ветеринар» появляется поле ввода специализации.
- Валидация форматов данных (email, регулярные выражения логина, длина пароля, совпадение паролей).
- Авторизация по логину и паролю с поддержкой опции «Запомнить меня».
- Безопасный выход из системы (SignOut).

### 3. Личный кабинет Клиента (Владельца животного)
- Просмотр списка своих питомцев (кличка, порода, возраст, пол, вес, особенности здоровья).
- Добавление нового животного и редактирование существующих.
- Электронная медицинская карта каждого питомца с историей всех визитов, диагнозов и назначений.
- Онлайн-запись на приём: выбор питомца, врача, услуги, даты и времени, указание симптомов.
- Журнал своих записей с фильтрацией по статусам и датам.
- Возможность отменить предстоящую запись.

### 4. Рабочее место Ветеринара
- Список приёмов, назначенных к данному врачу.
- Фильтры приёмов по статусу («Запланирован», «В процессе», «Завершён», «Отменён») и датам.
- Поиск пациентов по кличкам, владельцам и диагнозам.
- Проведение приёма: внесение официального клинического диагноза, схемы терапии и медикаментов, рекомендаций, расчёт стоимости.
- Просмотр электронных медкнижек пациентов перед процедурой.

### 5. Административная панель (Администратор)
- Сводный дашборд с аналитикой: общее число пользователей, питомцев, приёмов, выручка клиники в рублях.
- Таблица последних зарегистрированных приёмов и пользователей.
- **Управление пользователями (CRUD):** поиск, фильтрация по ролям, редактирование данных, смена роли, сброс паролей, удаление.
- **Управление услугами клиники (CRUD):** создание новых услуг, установка цен и времени, редактирование, отключение/удаление.
- Полный контроль всех приёмов и карточек животных в клинике.

### 6. Защита и безопасность
- Защита страниц от доступа неавторизованных пользователей: при попытке открыть закрытые страницы неавторизованный пользователь перенаправляется на `/Account/Login`.
- Разграничение прав доступа: если клиент попытается открыть страницу администратора (`/Admin`), он перенаправляется на страницу `403 Доступ ограничен` (`/Account/AccessDenied`).
- Защита от подделки межсайтовых запросов (`[ValidateAntiForgeryToken]`).
- Проверка прав владения: клиент не может просматривать или редактировать чужих животных.
